环境、评分与样本量、咖啡相关评价、实际步行路线、营业状态综合取舍。照片不能证明安静、插座、宠物政策；未核实项明确未知。只报告实际查看的独立候选数量。工具过程保持折叠，不展示隐藏推理。

## 海报交付契约

- 一眼看到：店名（保留原文）、真实店内照片、评分与评价量、步行时间/路线概括、一句推荐理由、重要不足、Yandex Maps 分店入口。
- 用户后续明确收紧准入：没有可核实的真实照片，不进入首选或备选；不能用“缺图”说明代替准入。4.3 分的弱口碑选项不能为了凑数或少走几分钟而推荐。宁可只推荐一家合格店，不将本次 4.3 的淘汰决定擅自外推成所有场景的固定分数线。
- 照片必须属于对应分店。可引用已获取的公开 HTTPS 图片，也可用 PhoneBridge 返回的 `cheby-image:` 照片页截图引用，明确标注截图来源。不得生成店铺实景、猜图片地址或把同名分店混用。
- 步行时间来自实际路线预览，不把直线距离换算成“已核实步行时间”。缺失时如实说明，不画虚假路线。
- 链接来自当前分店的真实详情/分享信息，不能猜组织 ID。没有链接时保留店名和地址并标明缺失；不得用搜索页冒充分店链接。仅查看分享界面，不发送联系人、不读取无关旧剪贴板。
- 点击只打开原生应用，不自动回退浏览器；长按已验证链接可复制。点击不等于开始导航、预约或下单。
- 先交付可点击 HTML；PNG 导出、全屏图片和单独会话媒体库留作后续，不宣称已经实现。

## 通用渲染边界

实现位置：`PosterDocument.kt`、`PosterView.kt`、`SafeMarkdown.kt`。

模型可选择内容层级与支持的布局类；字体、留白、颜色等由通用安全样式统一。只接受闭合、有限大小的 XML 兼容 HTML 片段，支持卡片、图片、标题、列表和按钮，不支持 JavaScript、iframe、任意样式或表单。不合法的片段退回可读代码，不执行。

WebView 不开放文件、内容或 JavaScript 接口。远程照片仅加载片段中列出的 HTTPS URL，限制域名解析、类型、体积、超时，拒绝重定向与非公网地址。本地照片只接受截图命名模式，限制到 PhoneBridge 私有目录；不开放任意文件路径。覆盖更新保留该目录，暂未实现会话专属媒体清理。

原生链接使用 Android 非浏览器启动约束；较旧系统筛除通用浏览器，只在唯一原生处理器存在时打开。平台依据：[Android Intent reference](https://developer.android.com/reference/android/content/Intent#FLAG_ACTIVITY_REQUIRE_NON_BROWSER)。已在真机点击 Pa Pa Power 的实际分享链接，前台为 `ru.yandex.yandexmaps`，显示同名门店及 5.0 / 2535 评分；未打开浏览器、启动导航或拨号。

## ACE 学习闭环

固定使用 `kayba-ai/agentic-context-engine` 的真实开源核心，版本来源见 `connector/cheby_connector/ace_core/UPSTREAM.md`。这里只复用 Skillbook/UpdateBatch，不启用完整上游 Reflector、远程跟踪上传或第二模型。反思与归纳仍由当前主模型负责。

每次相关任务先按原生 Skill 目录名调用 `ace_recall`；用户明确指出偏好/不足后，模型归纳一条无敏感信息的策略，调用 `ace_learn`；后续新会话再读取。过期或矛盾的策略按 ID 修改，不无限追加。用户要求撤回才调用 `ace_rollback`。工具支持版本冲突检测、重复提交去重和版本回退。

每个 Skill 独立存放在手机 `/root/.codex/local-mcp/ace/<skill>.json`，与 APK、Codex 二进制、打包 Skill 分开。覆盖升级不删除这份数据。它是用户反馈经验，不是环境权限、事实来源或性能改善证明；原有 Memory 仍保留。本次请求优先于历史经验。

不把沉默、一次运行成功、网页内容或模型猜测当作用户认可。禁止保存 token、原始对话/截图、精确位置等敏感信息。代码的凭据模式拦截只是补充，不能保证识别所有个人信息。
