# ChebyAgent 0.7.0：纯手机安装与使用

状态：0.7.0 已在 Huawei ALN-AL00 真机走查；这不等于已覆盖所有 Android 品牌。
正式 APK、SHA-256、签名证书摘要和对应源码均以 GitHub Release 页面为准。

## 安装前

准备 ARM64 Android 手机；当前工程最低 Android 9，本轮指定验证机为
Huawei ALN-AL00，不能据此承诺所有品牌都可用。需要足够空间解压内置环境，
最终所需空间和初始化时间以新机实测为准。

手机需要能够访问选定的模型服务，并持有自己的 API Token 和可用额度。
安装包包含 Codex 与 Linux 运行依赖，首次初始化不应下载这些依赖；
模型回答、地图、租房和外卖服务仍需要网络。

本包占用 Termux 的应用标识。若手机已有 Termux，不要直接卸载或清数据；
先备份其中的工作并核对迁移方案。本轮实验机初查未安装 Termux。

## 安装和授权

1. 使用手机浏览器打开项目 GitHub Release 页面，下载对应版本 APK，
   核对版本和发布记录；不要使用来路不明的转发安装包。
2. 在系统提示时仅为本次使用的浏览器或文件管理器允许安装应用，安装后关闭该授权。
3. 打开应用，等待“正在离线安装内置 Codex”完成。初始化期间保持应用在前台。
   失败时记录屏幕上的简短错误，不要清除应用数据来试错。
4. 在更多菜单选择“打开 ChebyNode 无障碍授权”，根据系统提示开启该服务。
   无障碍用于读取及操作手机界面。截图若出现系统授权，按当前任务选择允许。
5. 先安装并打开 RuStore，把它作为本轮俄区应用的更新入口；再通过 RuStore 安装或更新
   Yandex Maps、Cian、Yandex Go。使用你自己的账号完成各 App 的正常登录与定位授权，
   验证码由你本人填写。外卖是否可用以当前地区的 Go 页面为准。

华为系统可能在安装 APK 时连续显示来源授权和风险确认。只对已核对版本、SHA256
和项目签名的 ChebyAgent 安装包继续，并按页面完成本次确认。无需、也不应为了减少提示
全局关闭锁屏、病毒扫描或其他手机安全能力；当前版本尚未实现系统级静默安装。

无需另装 Termux，也无需通过电脑输入命令。

## 填写模型设置

在更多菜单打开“服务与登录”，可选 GLM 5.3 Flash、MiniMax M3 或
GPT-5.6 Sol。Token、服务地址和登录信息作为软件级服务配置持久化；
模型与推理强度属于会话，由 Codex `model/list` 返回每个模型的原生档位。GLM 默认低强度，
MiniMax 默认中强度，Sol 默认高强度。“保存成功”不表示服务已接通。

普通 Z.AI API 默认地址为 `https://api.z.ai/api/paas/v4`；若 Token 属于 Coding Plan，
按账号产品使用 `https://api.z.ai/api/coding/paas/v4`。应用在手机本机回环地址运行
Responses → Chat Completions 适配层，用户不需要另装服务，也不要把回环地址改成公网地址。

三个模型入口都按原生图片输入接入；不再提供独立视觉 MCP。
未成功发送和理解图片时，助手不能声称已经看过。

已保存的 Token 不回显；输入框留空保留原值，明确选择清除才移除。
改变服务地址后须重新提供 Token，旧 Token 不会自动发送到新地址。
设置页受安全窗口保护，不要把凭证贴入聊天或拍照发送。

保存后空闲时应用会重连。若任务仍在进行，它继续使用原配置；
任务结束后可点“应用已保存的模型配置”。不要把保存次数当作模型测试次数。

内置手机工具由 Agent 自动使用，界面不展示 MCP 配置入口。
远端服务必须由你逐项确认授权。只添加你信任并明确希望助手使用的服务。

## 先做一项简单验证

新建会话，先输入“用中文回答：2+2等于多少？”，再要求打开 Yandex Maps 并读取当前页面。
分别确认文字回答、工具实际执行、截图可显示、视觉确实返回结果。
这些通过后再做生活任务。

可以使用这些短指令，并在同一会话补充条件：

- “找附近最好的咖啡厅” → “安静，能坐着办公” → “带我去推荐的那家”
- “找附近最好的理发店” → “男士剪发，今天营业”
- “找附近正规的放松按摩，90分钟”
- “找附近适合萨摩耶洗澡、吹干和梳毛的店”
- “帮我找合适的房子”——随后提供预算、地区和租期
- “帮我打车去冬宫”——默认 Business，检查起终点和实时价格
- “帮我点个外卖”——提供地址、偏好和预算，检查购物车总价

导航默认步行。默认安全边界只到提交前确认：不实际叫车、下单、支付、预约或发送消息。
店铺营业不等于有预约空档；房租标价不等于总费用；购物车也不代表订单已提交。

## 遇到问题

服务鉴权失败：检查当前模型的 Token、服务地址、额度和网络。
不要发送完整 Token 或含凭证的日志。

手机工具不可用：检查无障碍服务及目标 App 的前台状态；地图没有位置时，
在系统和地图 App 中检查定位授权。助手无法替你绕过账号验证。

图片无法读取：确认当前模型凭证有效、图片能正常打开；
超过支持范围或看不清的图片应重新选择，不能把猜测当识别结果。

任务中断：先使用任务中的取消或恢复入口，并检查当前终态；
不要重复点击可能提交订单的按钮。永久转圈或不能取消应记录为缺陷。

## 更新、回退与凭证

后续版本必须使用同一项目签名才能覆盖更新。最终发布材料会附校验值与签名核对信息。
当前候选版的更新是整个约 379 MiB APK 覆盖安装，还不支持签名小补丁。
安装过程可能仍出现华为风险提示；只对已核对校验值的本项目 APK 继续，
不要为了省提示而全局关闭扫描、锁屏或其他手机安全能力。
旧 APK 已保留，但不同签名或更低版本可能不能直接覆盖安装；
卸载会丢失应用私有数据，不承诺任意版本无损降级。

不要将模型 Token、签名密钥或个人账号分享给其他测试者。每位使用者自行配置凭证。
正式指南须在独立手机走查后补齐准确下载入口、空间占用、耗时与回退步骤。

## 1.0 发布前手机走查清单

以下每一项都必须在最终签名 APK 上由非开发者只按本文完成；没有现场证据时保持未通过。

- [ ] 能从 GitHub Release 找到正确 APK，并核对版本、SHA256 和签名说明。
- [ ] 能在华为系统提示中仅授权本次安装来源并完成安装。
- [ ] 首次启动在无依赖下载的条件下完成内置环境初始化；记录可用空间和耗时。
- [ ] 能打开并授权 ChebyNode 无障碍服务，关闭并重开应用后仍可执行截图工具。
- [ ] 能填写 GLM Token、选择 `low`、保存后完成精确的 `2+2` 文字验证。
- [ ] 设置页提供三个多模态模型及各自强度，不出现独立视觉 MCP 或通用 MCP 配置入口。
- [ ] 能从 RuStore 安装或更新 Yandex Maps、Cian、Yandex Go，并完成用户侧登录/定位。
- [ ] 能完成一项地图截图理解和一项生活场景，到提交前停下且不产生付款或预约。
- [ ] 同签名覆盖更新后，模型设置和会话仍在；重启手机后本机连接能够恢复。
- [ ] 能按最终说明找到回退资产，理解卸载会丢数据，并在不清数据的前提下完成已支持的回退演练。
